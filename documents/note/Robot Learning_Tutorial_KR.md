# 초록 (Abstract)

로봇 학습은 머신러닝의 급속한 발전과 대규모 로봇 데이터의 증가로 인해 변곡점에 있다. 고전적인 모델 기반 방법에서 데이터 주도의 학습 기반 패러다임으로의 전환은 자율 시스템에서 전례 없는 능력을 열어주고 있다. 이 튜토리얼은 현대 로봇 학습의 전반을 다루며, 강화학습(Reinforcement Learning)과 행동 복제(Behavioral Cloning)의 기초 원리부터, 다양한 태스크와 로봇 플랫폼에서 작동할 수 있는 언어 조건부 범용 모델까지 안내한다. 이 작업은 연구자와 실무자를 위한 가이드로, 로봇 학습 발전에 기여하는 데 필요한 개념적 이해와 실용적 도구를 lerobot으로 구현된 예제와 함께 제공하는 것을 목표로 한다.

# 머리말 (Foreword)

로봇공학은 본질적으로 학제간 분야이며, 1960년대 시작 이래 전례 없는 발전을 목도하고 있다. 그러나 Unimate가 데뷔한 지 60년 이상이 지난 지금도, 로봇은 인간이 살아가는 풍요롭고, 비구조적이며, 동적인 세계에 완전히 통합되지 못했다. 수십 년에 걸쳐 수많은 학문 분야가 자율 로봇 시스템을 만드는 도전에 대한 엄청난 가능성을 보여주었다. 이 튜토리얼은 현대 머신러닝이 자율 로봇 개발에 핵심적인 역할을 할 수 있는지에 대한 논쟁에서 분명한 입장을 취한다: 우리는 그렇다고 믿는다.

그럼에도 불구하고, 지난 60년간 학계와 산업계에서 고전 로봇공학에 대해 축적된 연구 자산은 순수하게 학습 기반 방법만을 위해 버리기에는 너무나 가치 있다고 말할 수 있다. 하지만 고전 로봇공학과 현대 머신러닝의 상호작용은 아직 초기 단계이며, 통합으로 가는 길은 아직 명확히 정의되지 않았다. 따라서 우리의 목표는 오늘날 로봇 학습에서 가장 관련 있다고 생각하는 접근 방식을 제시하는 것이다.

**이 튜토리얼은… → 아래 내용에 대한 전문 교재가 아니라는 뜻. 이걸 알아야 읽을 수 있다는 뜻이 아님.**

- 로봇공학, 매니퓰레이션, 부족 구동 시스템에 대한 포괄적 가이드를 _목표로 하지 않는다_.
- 통계적 또는 딥러닝 입문서를 _목표로 하지 않는다_.
- 강화학습, 확산 모델, 플로우 매칭에 대한 심층 분석을 _목표로 하지 않는다_.

대신, 우리의 목표는 이러한 서로 다른 아이디어들이 왜 수렴되어 현대 로봇 학습이라는 흥미로운 분야를 형성하고, 오늘날 우리가 목격하는 전례 없는 발전을 이끌어내고 있는지에 대한 직관적인 설명을 제공하는 것이다. 이러한 정신으로, “만능 재주꾼(jack of all trades)이 전문가 하나보다 나을 때가 많다”라는 격언을 따른다.

우리는 이 튜토리얼이 로봇 학습으로의 여정에서 가치 있는 출발점이 되기를 진심으로 바란다.

# 1장. 소개 (Introduction)

자율 로봇공학은 반복적이고, 피곤하고, 위험한 수작업으로부터 인간을 해방하겠다는 전제를 가지고 있다. 따라서 로봇공학은 1950년대 처음 등장한 이래 널리 연구되어 왔다. 최근 머신러닝(ML)의 발전은 인간의 전문 지식과 모델링 능력 대신 대량의 데이터와 연산력을 활용하여 로봇공학 문제를 해결하는 비교적 새로운 부류의 방법론 개발을 촉발했다.

로봇공학 연구의 최전선은 실제로 고전적인 모델 기반 제어 패러다임에서 점점 멀어지고 있으며, ML의 발전을 수용하여 다음을 가능하게 하는 것을 목표로 한다:

1. **일체형 인지-행동 제어 파이프라인(Monolithic Perception to Actoin Pipeline)** — 카메라 이미지(인지)를 넣으면 바로 모터 명령(행동)이 나오는 하나의 신경망. 중간 단계를 사람이 설계할 필요 없이, 전체가 하나의 시스템으로 end-to-end 학습된다.
    - **고전적 방식**: 기존 방식의 경우 여러 모듈이 순서대로 작동함(카메라로 본다 → 물체를 인식한다 → 경로를 계획한다 → 관절 각도를 계산한다 → 모터에 명령을 보낸다)
    - **문제점**: 한 단계에서 오류가 나면 다음 단계로 전파됨. (조명이 바뀌면 perception틀어짐. 계획이 틀어지면 동작이 실패함. 모듈 하나가 바뀌면 나머지를 재조정 해야함.)
    - **학습기반**: 경우 카메라 이미지를 넣으면 바로 모터 명령이 나오는 하나의 신경망으로 대체. 즉 전체가 하나의 시스템으로 EtoE로 학습됨. → monolithic(일체형) 이라고 불리는 이유.

2. **다중 모달리티 데이터 주도 특징 추출 전략(Multi-modal Data-driven Feature Extractoin)** — RGB, 깊이, 촉각, 관절 상태 등 여러 모달리티의 원시 데이터를 그대로 입력받아, 태스크에 유용한 특징을 신경망이 스스로 학습한다.
    - **고전적 방식**: 로봇이 RGB카메라, Depth, 촉각, 엔코더 등 다양한 센서를 가지고 있으면, 각 센서별로 사람이 의미있는 특징을 추출하는 파이프라인을 만들어야 함.
    - **문제점**: 센서가 추가되거나, 태스크가 바뀔 때 마다 새로운 특징 추출기를 만들어야 함. 센서 정보를 통합하는것도 어려움.
    - **학습기반:** 신경망이 RGB, 깊이, 톡각, 관절상태 등 여러 모달리티의 raw data를 입력받아서 task 에 유용한 특징을 **스스로 학습**. 사람이 뭘 봐야하는지 정해줄 필요 없음.

3. **정밀한 세계 모델에 대한 의존도 감소** — 세계의 물리법칙을 수식으로 표현하는 대신, “이런 상황에서 이렇게 하면 성공한다”는 데이터로부터 직접 학습한다.
    - **고전적 방식**: 로봇 팔을 움직이려면, 로봇의 정확한 기구학 모델, 물체의 물리적 속성(무게, 마찰계수, 탄성 등), 환경의 정밀한 3D모델 등이 필요. (IK, FK, 등이 이런 모델에 의존하는 방법론)
    - **문제점**: 현실 세계는 완벽히 모델링하는것이 어려움. 천의 변형을 정확히 수식으로 표현하는건 불가능함. 모델이 조금만 부정확해도 실제 동작이 실패할 가능성 있음.
    - **학습기반:** 물리법칙을 수식으로 표현하는 대신, 이런 상황에서 이렇게 하면 성공한다는 데이터로부터 직접 학습함. 물리 모델이 없어도. 충분한 상호작용 데이터가 있으면 정책 학습이 가능. 동역학이 복잡하거나 알려지지 않은 경우에 유리함.

4. **증가하는 공개 로봇 데이터를 활용할 수 있는 더 나은 포지셔닝** — GPT가 더 많은 텍스트로 좋아지듯이, 로봇 정책도 더 많은 로봇 데이터로 좋아질 수 있다. 학습 기반 방법만이 이 데이터 증가 트렌드의 혜택을 직접적으로 받을 수 있다.
    - **배경**: 최근 몇 년간 로봇 데이터셋이 폭발적으로 늘어남. [Open X-Embodiment](https://robotics-transformer-x.github.io/) 처럼 대규모 학술데이터셋 뿐 아니라, HuggingFace Hub에 있는 개인들이 올리는 소규모 데이터셋도 계속 증가하고있음.
    - **문제점:** 전통적인 동역학 기반 방법은 수학 모델과 물리 법칙에 기반하므로, 데이터가 아무리 많아져도 그 데이터를 활용할 방법이 없음(IK Solver는 더 많은 시연 데이터를 본다고 성능이 좋아지지 않음)
    - **학습기반**: GPT가 더 많은 텍스트 데이터로 더 좋아지고, 이미지 모델이 더 많은 이미지로 좋아지듯이.. 로봇 정책도 더 많은 로봇 데이터로 좋아질 수 있음. $\pi_0$나 SmolVLA와 같은 파운데이션 모델의 기반 논리이기도 함.

로봇공학은 근본적으로 본질적으로 학제간 분야이며, **소프트웨어와 하드웨어 모두에 광범위한 전문성이 필요하다.** 학습 기반 기술의 통합은 이 기술 스펙트럼을 더욱 넓히며, 연구와 실용적 응용 모두의 문턱을 높인다.

**lerobot**은 전체 로봇공학 스택과 엔드투엔드로 통합되도록 설계된 오픈소스 라이브러리다. 접근 가능한 실제 로봇에 중점을 두고:

- 매니퓰레이션, 로코모션, 전신 제어를 위한 많은 공개 로봇 플랫폼을 지원
- 통합된 저수준 로봇 구성 읽기/쓰기 방식을 구현
- 커뮤니티가 효율적으로 데이터셋을 기록하고 공유하는 데 사용하는 고유 로봇 데이터셋 포맷인 LeRobotDataset을 제공
- RL 및 BC 기반의 최신 알고리즘을 Pytorch로 효율적으로 구현
- 행동 계획과 행동 실행을 분리하는 최적화된 추론 스택을 제공

**이 튜토리얼의 구성:**

- **2장**: 고전 로봇공학의 기초를 검토하고, 동역학 기반 접근 방식의 한계를 소개
- **3장**: 동역학 기반 방법의 한계를 자세히 설명하고, 로봇공학 문제를 해결하는 실용적 접근법으로 강화학습(RL)을 소개
- **4장**: 전문가 시연을 자율적으로 재현하기 위해 행동 복제(BC) 기법을 활용한 단일 태스크 학습을 다룸
- **5장**: 대규모 다중 태스크 및 다중 로봇 데이터 코퍼스에서 학습하여 범용 모델을 개발하는 최근 기여(로봇 파운데이션 모델)를 제시

## 1.1 LeRobotDataset

LeRobotDataset은 lerobot의 가장 영향력 있는 기능 중 하나로, 로봇 데이터가 로봇 학습에서 점점 더 중심적인 역할을 하고 있다는 관찰에 따라 개발되었다. lerobot은 로봇 학습 연구의 특정 요구사항을 해결하기 위해 설계된 **표준화된 데이터셋 형식을 정의하여**, 센서모터 데이터, 다중 카메라 피드, 텔레오퍼레이션 상태 등 **다양한 모달리티에 걸쳐 로봇 데이터에 대한 통합된 편리한 접근을 제공**한다.


💡 LeRobotDataset 특징

"로봇 데이터의 특수한 요구사항(다중 모달리티, 시계열, 대용량 비디오)에 맞춰 저장 구조를 설계하고, PyTorch/HuggingFace 생태계와 매끄럽게 연결되도록 만든 표준 포맷"

- **표준화**: 파편화된 로봇 데이터(실험실마다 저장 방식 다르고, 로봇마다 센서 구성, 카메라, frame rate등이 모두 다름)를 하나의 통일된 포맷으로 정리함. 별도 전처리 없이 로드해서 사용이 가능
- **최적화**: 로봇 데이터의 특성상 모달리티별로 최적의 접근 / 저장 전략이 다름.
    - **관절 및 액션**: 저차원 / 고빈도. Parquet 파일에 메모리 매핑 방식으로 저장. 빠르게 읽고 메모리 적게 씀.
    - **카메라 영상**: 고차원. 용량 큼. 프레임을 개별 이미지로 저장하면 파일수 아주 많으니, 에피소드 단위로 **MP4비디오**로 묶어서 저장. 파일 시스템 부담 줄이면서도 필요한 프레임만 디코딩해서 꺼낼 수 있음
    - **메타데이터**: JSON으로 관리해서, “이 에피소드가 어떤 파일의 몇 번째 위치에 있는지”빠르게 찾을 수 있게 함.
- **스트리밍 모드:** 대규모 데이터셋을 모두 로컬에 받지 않고, HuggingFace Hub에서 스트리밍 하면서 학습할 수 있게함.(80 - 100 Iteration / sec정도의 속도.) **GPU비싼 환경에서 스토리지 많이 잡을 필요 없게함**.
- **delta_timestamps**: 현재 프레임 기준으로 0.2초 전, 0.1초 전 이미지 가져와라 등의 윈도우 연산을 데이터셋 레벨에서 지원함. RL이나 BC알고리즘이 과거 관측 히스토리 필요로 할때 유용

데이터셋은 항상 세 가지 주요 구성 요소로 조직된다:

- **테이블 데이터**: 관절 상태, 액션 등의 저차원 고빈도 데이터는 효율적인 메모리 매핑 파일에 저장
- **시각 데이터**: 대량의 카메라 데이터를 처리하기 위해 프레임은 MP4 파일로 연결 및 인코딩. 같은 에피소드의 프레임은 항상 같은 비디오에 그룹화
- **메타데이터**: 데이터셋의 구조를 설명하는 JSON 파일 모음으로, 특징 스키마, 프레임 레이트, 정규화 통계, 에피소드 경계를 포함

주요 파일 구조:

- `meta/info.json` — 전체 데이터셋 스키마, 모든 특징 정의, fps, 버전 정보
- `meta/stats.json` — 전체 데이터셋에 걸친 각 특징의 집계 통계(평균, 표준편차, 최소, 최대)
- `meta/tasks.jsonl` — 자연어 태스크 설명과 정수 태스크 인덱스 간 매핑
- `meta/episodes/*` — 각 에피소드의 메타데이터(길이, 해당 태스크, 데이터 위치 포인터)
- `data/*` — 프레임별 테이블 데이터, parquet 파일 사용
- `videos/*` — 모든 시각 관측 스트림의 MP4 비디오 파일

LeRobotDataset은 스트리밍 모드도 지원하여, 대규모 데이터셋을 메모리와 스토리지 제약 없이 처리할 수 있다. 스트리밍 모드는 고성능 배치 처리(약 80-100 it/s)와 높은 수준의 프레임 랜덤화를 지원한다.

# 2장. 고전 로봇공학 (Classical Robotics)

> _“너의 적을 알라 […]” — 손자_

**TL;DR** — 학습 기반 로봇공학 접근법은 (1) 태스크와 플랫폼 전반에 걸친 일반화, (2) 인간 전문성에 대한 의존도 감소, (3) 데이터 생산의 역사적 추세 활용 필요성에 의해 동기 부여되며, 이는 모두 동역학 기반 기술이 전통적으로 간과해온 것이다.

---

## 2.1 명시적 모델과 암묵적 모델

로봇공학은 유용하고, 신뢰할 수 있으며, 안전한 방식으로 물리적 세계에서 인공적인 운동을 생산하는 것에 관심을 둔다. 따라서 로봇공학은 본질적으로 학제간 영역이다: 물리적 세계에서 자율적 운동을 생산하려면 최소한 서로 다른 소프트웨어(운동 계획자)와 하드웨어(운동 실행자) 구성 요소를 인터페이싱해야 한다.

로봇 운동을 생산하는 방법은 다양하다:

- **명시적 모델 (동역학 기반)**: 로봇 강체의 기계적 원리와 환경 장애물과의 상호작용에 대한 **정밀한 설명을 활용**
- **암묵적 모델 (학습 기반)**: 운동을 여러 센서모터 데이터로부터 학습할 **통계적 패턴으로 취급**

이 두 극단 사이에 다양한 방법이 개발되었다. 예를 들어, Hansen et al. (2022)은 **학습 기반 시스템이 TD-러닝을 모델 예측 제어(MPC)와 결합하여 문제의 물리학 정보로부터 이점을 얻을 수 있음**을 보여주었다.

💡 MPC(Model Predictive Control, 모델 예측 제어)는 직관적으로 이해하면 "짧은 미래를 시뮬레이션해보고, 가장 좋은 첫 번째 행동만 실행하고, 다시 계획하기를 반복하는 것"입니다.

튜토리얼에서 Hansen et al. (2022)이 TD-러닝과 MPC를 결합했다는 건, MPC의 "동역학 모델이 필요하다"는 부분을 학습으로 보완한 거예요. 물리 모델이 완벽하지 않더라도, 학습된 가치 함수가 "이 상태가 얼마나 좋은지"를 알려줘서 MPC의 계획 품질을 높여주는 방식입니다. 이게 바로 논문에서 말하는 "명시적 모델과 암묵적 모델 사이"에 위치하는 하이브리드 접근이에요.

---

## 2.2 다양한 유형의 운동

대부분의 경우, 로봇공학은 거의 완전히 강성인 링크를 연결하는 **관절을 구동하여 운동을 생산하는 것**과 관련된다. 로봇공학의 초점 영역 간 주요 구분은 **생성된 운동이 수정하는 것이 무엇인지에 기반**한다:

1. **매니퓰레이션** — 환경의 절대적 상태를 수정 (손재주를 통해)
2. **로코모션** — 환경에 대한 로봇의 상대적 상태를 수정 (이동성 기술 발휘)
3. **모바일 매니퓰레이션** — 두 가지의 조합. 환경과 상호작용하면서 동시에 환경 내에서 이동

고전적 연구 체계는 점점 더 학습 기반 접근법으로 보완되고 있다. ML은 실제로 전체 로봇공학 스택에 걸쳐 특히 혁신적으로 작용했으며, 먼저 계획 기반 기술에 개선된 상태 추정을 제공한 다음, 엔드투엔드로 컨트롤러를 대체하여 인지-행동 방법을 만들어냈다.

---

## 2.3 예제: 평면 매니퓰레이션

로봇 매니퓰레이터는 일반적으로 일련의 링크와 관절로 구성되며, 체인 구조로 연결되어 최종적으로 엔드 이펙터(end-effector)에 도달한다. 구동되는 관절은 링크의 운동을 생성하는 역할을 하고, 엔드 이펙터는 목표 위치에서 특정 동작을 수행하는 데 사용된다(예: 그리퍼 엔드 이펙터를 닫거나 열어 물체를 잡거나 놓기).

최근 ALOHA, ALOHA-2, SO-100/SO-101 플랫폼과 같은 저가 매니퓰레이터의 개발은 Franka Emika Panda 팔과 같은 전통적인 플랫폼에 비해 이러한 로봇의 접근성이 높아져 로봇공학에 대한 진입 장벽을 크게 낮췄다. 특히 SO-100은 수백 유로 수준의 비용으로 수 시간 내에 3D 프린팅으로 완전히 제작할 수 있다.

이 섹션에서는 SO-100을 2자유도 평면 매니퓰레이터로 단순화하여 전통적인 접근법을 분석한다:

- **순방향 기구학 (FK)**: 로봇 구성(관절 각도)을 엔드 이펙터 자세로 매핑
    
    - **관절 각도가 이러면? 엔드이펙터의 위치는 어떻게되지?**
- **역방향 기구학 (IK)**: 엔드 이펙터 자세로부터 구성을 재구성
    
    - **손 끝을 여기에 두고싶은데? 관절 각도를 얼마로 해야하지?**
- **미분 역기구학 (diff-IK)**: 구성 대신 관절 속도를 풀어 IK를 보완하며, 야코비안 행렬의 psuedo inverse을 사용하여 폐쇄 형태 해를 제공
    
    - **End effector를 원하는 속도로 움직이려면? 각 관절의 속도를 어떻게 구해야햐지?**
    - 야코비안 행렬(J(q)): 관절 속도가 변하면 손 끝 속도가 얼마나 변하는지를 나타냄.
    
    $$ \dot{p}=J(q)⋅\dot{q}\\ $$$$ \dot{q} = J(q)^+ ⋅ \dot{p}^*$$
    
    
    **p = 엔드 이펙터(손끝) 위치** (workspace 에서의 위치)
    
    **q = 관절 각도** (로봇의 configuration)

diff-IK는 잘 통제되고 정적인 환경(예: 통제된 제조 환경의 산업용 매니퓰레이터)에서 유효한 옵션이다.

### 2.3.1 피드백 루프 추가

![image.png|461](image_01.webp)

모델링/추적 오류나 환경에 모델링되지 않은 동역학이 존재하는 경우 diff-IK의 성능이 크게 저하될 수 있다. 모델링 오류, 센서 노이즈 및 기타 교란의 영향을 완화하기 위해, **고전적 파이프라인은 관심 있는 양을 루프백하는 피드백 제어로 diff-IK를 보강한다.**

**PID 제어, 선형 2차 조정기(LQR), 모델 예측 제어(MPC)** 등 더 고급 기술을 사용하여 추적을 안정화하고 적당한 섭동을 거부할 수 있다. 그러나 피드백 제어 역시 고유한 문제가 있다: 게인 튜닝은 힘들고 시스템별로 다르며, 매니퓰레이션 태스크에서는 간헐적 접촉이 하이브리드 동역학과 야코비안의 불연속성을 유발하여 컨트롤러의 안정성 보장을 어렵게 한다.

- 게인 튜닝 어렵고, 시스템별로 게인이 다름.(게인은 control algorithm의 파라미터)
- 간헐적 접촉이 동역학과 야코비안의 불연속을 유발함.

## 2.4 동역학 기반 로봇공학의 한계

60년 이상의 로봇공학 연구에도 불구하고, 자율 로봇은 여전히 (1) 로봇 플랫폼(다양한 매니퓰레이터, 다양한 로코모션 플랫폼 등)과 (2) 태스크(신발끈 묶기, 다양한 물체 조작) **전반에 걸쳐 인간 수준의 성능으로 물리적 세계에서 태스크를 수행하는 데 거의 불가능하다.**

동역학 기반 로봇공학 파이프라인의 주요 한계:

**통합 과제**: 감지, 상태 추정, 매핑, 계획, (diff-)IK, 저수준 제어가 고정 인터페이스를 가진 별개 모듈로 개발되었다. 이러한 모듈을 파이프라인으로 연결하는 것은 오류가 발생하기 쉬우며, 변경이 발생할 때마다 취약성과 복합 오류가 나타난다.

- 각 모듈을 파이프라인으로 연결하면 오류 발생하기 쉬워지고, 변경 발생할때마다 취약성 / 복합 오류 발생함

**확장성 제한**: 고전적 계획자는 콤팩트하고 충분하다고 가정된 상태 표현에서 작동하며, 원시 이질적 데이터 스트림에 대해 직접 추론하도록 확장하는 것은 간단하지 않다. 높은 차원의 인지 입력(RGB, 깊이, 촉각, 오디오)을 통합하려면 의미 있는 특징을 추출하기 위한 방대한 엔지니어링 노력이 필요하다.

- 고전적인 Planning은 높은 차원의 입력에서 의미있는 특징 추출하는것이 어려움.

**부정확한 모델링**: 복잡한 시스템의 접촉, 마찰, 순응성에 대한 정확한 모델링을 개발하는 것은 여전히 어렵다. 강체 근사는 변형 가능한 물체가 있을 때 종종 불충분하다.

- 고전적인 방법을 위한 정확한 시스템 모델링이 대단히 어려움.

**데이터 추세 간과**: 동역학 기반 방법은 공개적으로 사용 가능한 로봇 데이터셋의 최근 증가를 간과한다. 데이터가 비전과 자연어 이해의 발전의 초석이었던 것처럼, 이 추세는 태스크와 플랫폼 공간에서의 일반화를 가능하게 할 전제를 가지고 있다.

- 데이터셋의 폭발적 증가에 혜택을 받을 수 있는 구조가 아님.

이러한 한계들을 종합하면,

(1) 인지와 제어를 더 긴밀하게 통합하고

(2) 전문가 모델링 개입을 줄이면서 태스크와 플랫폼 전반에 걸쳐 적응하며

(3) 더 많은 로봇 데이터가 사용 가능해지면서 성능이 우아하게 확장될 수 있는 학습 기반 접근법의 탐색을 동기 부여한다.

# 3장. 로봇 (강화) 학습 (Robot Reinforcement Learning)

> _“문제가 아니라 해답을 근사하라 […]” — 리처드 서턴_

**TL;DR** — 값비싼 고충실도 시뮬레이터의 필요성은 실제 하드웨어에서 직접 안전하게 학습할 수 있는 샘플 효율적 알고리즘을 사용하여 실제 데이터로부터 학습함으로써 해결할 수 있다.

---

학습 기반 기술은 2장에서 제시된 한계를 자연스럽게 해결한다. 특히:

- 일체형 예측-행동 파이프라인(시각운동 정책)에 의존하여 센서모터 입력을 예측된 행동으로 직접 매핑
- 다양한 입력 모달리티를 통합할 수 있게 함
- 명시적 모델링을 완전히 우회하고 상호작용 데이터에만 의존 가능
- 증가하는 로봇 데이터를 자연스럽게 활용할 수 있는 위치

두 가지 주요 방법론이 부상했다: **강화학습(RL)**과 **행동 복제(BC)**.

**lerobot에서 현재 사용 가능한 로봇 학습 정책:**

**1~5번은 모방 학습(BC) 계열**이고, **6번은 강화학습(RL) 계열**, **7번은 RL+모델 기반 하이브리드**

4, 5번은 언어 조건부 범용 모델(VLA)이라서 5장에서 다루는 파운데이션 모델에 해당함.

1. ACT (Action Chunking with Transformers): 트랜스포머 기반 모방 학습 정책. 한 번에 여러 타임스텝의 행동을 묶어서("청킹") 예측한다. CVAE 구조를 써서 같은 상황에서 여러 가지 행동이 가능한 다중 모달 문제를 처리한다. **약 80M 파라미터로 가볍고, 단일 GPU에서 수 시간이면 학습 가능**해서 lerobot 입문 시 가장 먼저 추천되는 정책이다. 단, 단일 태스크 모델이라 태스크가 바뀌면 재학습이 필요하다.

2. Diffusion Policy: 확산 모델을 행동 생성에 적용한 정책. 노이즈에서 시작해서 역확산 과정을 거쳐 행동 청크를 생성한다. ACT보다 **표현력이 높고 학습이 안정적**이지만, 추론 시 여러 번의 역확산 스텝이 필요해서 **추론 속도가 더 느리다**. CNN 기반과 트랜스포머 기반 두 가지 아키텍처 변형이 있다.

3. VQ-BeT (Vector-Quantized Behavior Transformer): 행동 공간을 벡터 양자화(VQ)로 이산화한 뒤, 트랜스포머가 이산 행동 토큰을 자기회귀적으로 예측하는 방식. ACT나 Diffusion Policy가 연속 공간에서 행동을 생성하는 것과 달리, **행동을 "단어"처럼 취급**하는 접근이다. 다중 모달 행동 분포를 잘 처리하면서도, 이산 토큰 덕분에 학습이 안정적이다.

4. π₀: Physical Intelligence에서 개발한 VLA(Vision-Language-Action) 모델. 사전 학습된 VLM(PaLI-Gemma)을 백본으로 쓰고, **플로우 매칭 액션 헤드**로 연속 행동을 생성한다. 언어 명령("컵을 집어서 왼쪽에 놓아")을 이해하고, **여러 로봇 플랫폼에 걸쳐 작동**할 수 있는 크로스 엠보디먼트 모델이다. 대규모 사전 학습 → 특정 태스크 미세 조정의 2단계로 학습한다.

5. SmolVLA: Hugging Face에서 만든 **경량 VLA**. π₀와 같은 플로우 매칭 방식을 쓰지만, SmolVLM이라는 작은 VLM을 백본으로 써서 **모델 크기와 계산 비용이 훨씬 작다**. π₀ 수준의 언어 조건부 다중 태스크 제어를 더 접근 가능한 하드웨어에서 할 수 있게 하는 게 목표다. lerobot에 완전히 통합되어 있다.

6. HIL-SERL (Human-in-the-loop Sample-efficient RL): 유일한 **강화학습 기반** 정책. SAC를 기반으로, 사전 수집된 시연 데이터로 학습을 부트스트랩하고, **학습 도중에 인간이 개입하여 교정**할 수 있다. 보상은 학습된 분류기가 이미지로부터 자동 추론한다. Actor-Learner 아키텍처로 구현되며, **실제 로봇에서 1-2시간 학습으로 99%+ 성공률**을 달성하는 것이 핵심 강점이다.

7. TD-MPC: 앞서 설명한 MPC와 TD-러닝(강화학습)을 결합한 하이브리드 방식. **학습된 월드 모델**로 짧은 미래를 예측하면서, **학습된 가치 함수**가 계획의 품질을 평가한다. 순수 모델 기반도 아니고 순수 학습 기반도 아닌, 2장에서 말한 "명시적 모델과 암묵적 모델 사이"에 해당하는 접근이다.

8. **Pi0-FAST** — π₀의 변형인데, 플로우 매칭 대신 **자기회귀(autoregressive) 방식**으로 행동을 생성합니다. FAST(Frequency-space Action Sequence Tokenization)라는 토크나이저를 써서 행동을 이산 토큰으로 변환한 뒤 디코딩하는 방식이에요.

9. **Real-Time Chunking** — 더 반응성 높은 추론을 위한 기법

10. **GR00T N1.5** — NVIDIA와 협업해서 통합한 크로스 엠보디먼트 파운데이션 모델

## 3.1 강화학습(RL) 간략 소개

RL은 ML의 하위 분야로, 발전하는 환경에서 지속적으로 행동할 수 있는 자율 시스템(에이전트)의 개발에 근본적으로 관심을 둔다. 로봇공학에 있어 결정적으로 중요한 것은, RL 에이전트가 상호작용 데이터를 선호하며 문제 동역학의 명시적 모델을 우회하여 시행착오를 통해 개선된다는 것이다.

형식적으로, 에이전트와 환경 간의 상호작용은 일반적으로 **마르코프 결정 과정(MDP)**을 통해 모델링된다.

MDP는 튜플 M = ⟨S, A, D, r, γ, ρ, T⟩로 정의된다:

- **S** (상태 공간): 로봇 구성과 속도, 카메라나 오디오 스트림 같은 센서 데이터를 포함할 수 있다.
- **A** (행동 공간): 관절 토크, 관절 속도, 또는 엔드 이펙터 명령 등을 나타낼 수 있다.
- **D** (환경 동역학): 확률적일 수 있는 전이 함수.
- **r** (보상 함수): 전이의 바람직함을 목표 달성 맥락에서 측정하는 스칼라 값.
- **γ** (할인 인자): 즉각적 보상 vs 장기 보상에 대한 선호를 조절한다.

정책 π(행동|상태)는 에이전트의 행동 선택 전략을 나타내며, 할인된 누적 보상(return)을 최대화하도록 학습된다. 가치 함수 V^π(s)와 Q^π(s,a)는 상태와 상태-행동 쌍을 장기 보상 측면에서 판별하는 데 사용되며, 대부분의 RL 알고리즘의 핵심이다.

로봇공학에서 사용되는 연속 상태 및 행동 공간에 대한 주요 알고리즘으로는 TRPO, PPO, SAC 등이 있다.

## 3.2 실제 환경 RL

RL은 로봇공학을 위한 강력한 프레임워크이지만, 실제 환경에서는 **안전성과 학습 효율성 측면에서 여전히 한계가 있다**. 학습 초기에 행동은 탐색적이며 불규칙할 수 있어, **물리적 시스템에서 마모와 하드웨어 손상을 초래할 수 있다**.

시뮬레이션에서 학습하면 물리적 위험을 제거하고 수행 속도를 극적으로 높일 수 있지만, 시뮬레이터는 상당한 모델링 노력이 필요하며 **실제 환경과의 격차(현실 격차, reality gap)로 인해 정책 전이가 제한된다**.

- **도메인 랜덤화 (Domain Randomization)**: 학습 중 시뮬레이션 환경의 매개변수를 무작위화하여 견고성을 유도하는 기법이다. 하지만 어떤 매개변수를 무작위화할지 선택하는 것은 태스크별로 다르며, 과도한 무작위화는 과도한 정규화를 유발할 수 있다.
    
    ![image.png|438](image_02.webp)
    
- **샘플 효율적 RL**: SAC와 같은 off-policy 알고리즘은 **리플레이 버퍼를 통해 과거 전이를 재사용할 수 있어** on-policy 방법보다 샘플 효율성이 더 높다. **RLPD(Reinforcement Learning with Prior Data)**는 사전 수집된 데이터를 활용하여 SAC 에이전트의 학습을 효과적으로 가속화한다.
    
    - **RLPD**: 학습 시작 전에 이미 수집해둔 전문가 시연 데이터를 오프라인 리플레이 버퍼에 미리 넣어둔다
- **HIL-SERL** (Human-in-the-Loop, Sample Efficient Robot reinforcement Learning): 오프라인-투-온라인 RL에 학습 중 타겟팅된 인간 교정을 추가하고, 사전 데이터를 활용하여 (1) 보상 분류기를 학습하고 (2) 전문가 트랙젝토리로 RL 학습을 부트스트랩한다.
    
    - 학습 도중 인간이 개입해서 교정하는 데이터까지 오프라인 버퍼에 넣어두는것.
    - HIL-SERL을 사용해서 물체 잡기 태스크를 처음부터 학습한 과정을 상세히 기록한 글([https://ggando.com/blog/so101-hil-serl/](https://ggando.com/blog/so101-hil-serl/))

구현은 Actor-Learner 아키텍처를 사용한다:

- **Actor**: 고정된 정책 네트워크로 환경과 상호작용하고 관측값을 수집. 보상은 학습된 보상 분류기를 사용하여 추론
- **Learner**: 온라인과 오프라인 버퍼에서 동일 비율로 샘플링하여 정책 매개변수를 최적화

경험적으로, HIL-SERL은 다양한 매니퓰레이션 태스크에서 1-2시간 학습으로 거의 완벽한 성공률(99%+)을 달성한다.

💡**HIL-SERL 예시 상황: SO-100 로봇에게 "큐브 집기"를 가르치는 중**

**학습이 시작되면**, 로봇이 스스로 행동을 시도합니다. 초기에는 정책이 거의 랜덤이니까 엉뚱한 방향으로 팔을 휘두르겠죠.

**당신은 옆에서 게임패드를 들고 지켜보고 있습니다.** 그리고 로봇이 명백히 잘못된 행동을 할 때 — 예를 들어 큐브 반대 방향으로 가거나, 테이블을 내리찍으려 하거나, 그리퍼를 엉뚱한 타이밍에 닫으려 할 때 — **게임패드 버튼을 눌러서 제어권을 가져옵니다.** 그 순간부터 로봇은 정책의 명령이 아니라 당신의 조작을 따릅니다. 큐브 쪽으로 손을 유도하고, 적절한 위치에서 그리퍼를 닫아주고, 다시 버튼을 놓으면 로봇이 다시 자기 정책대로 행동합니다.

**핵심: 이 개입 데이터가 특별 취급된다**

당신이 개입한 동안의 데이터 (상태, 행동, 보상, 다음 상태)는 **온라인 버퍼와 오프라인 버퍼 둘 다**에 저장됩니다. 반면 로봇이 혼자 한 데이터는 온라인 버퍼에만 들어가요. 학습할 때 두 버퍼에서 절반씩 샘플링하니까, 인간 개입 데이터가 **더 자주 뽑혀서 학습에 더 큰 영향**을 미칩니다.

**왜 이게 효과적인가**

일반 RL은 로봇이 수많은 실패를 겪으면서 "아, 이건 안 되는구나"를 스스로 깨달아야 합니다. 근데 인간이 개입하면:

- 위험한 행동을 **즉시 막아서** 로봇이 안 부서짐
- "이 상황에서는 이렇게 해야 해"를 **실시간으로 시범** 보여줌
- 로봇이 스스로 발견하려면 수천 번 걸릴 좋은 행동을 **몇 번의 개입으로** 가르쳐줌

### 3.2.2 실제 환경 RL의 한계: 시뮬레이터와 보상 설계

RL의 실제 환경 학습은 여전히 두 가지 주요 한계가 있다:

1. 실제 환경 학습이 비용이 많이 드는 경우 시뮬레이션이 유일한 대안이지만, 고충실도 시뮬레이터 구축과 유지가 어렵다.
2. 보상 설계는 근본적으로 취약한 부분이다 — 조밀한 보상을 설계하는 과정은 오류가 발생하기 쉽고 인간의 전문성과 직관에 크게 의존한다.

잠재적으로 대규모 인간 시연 코퍼스로부터 행동 복제(BC)를 통해 학습하는 발전이 이 두 가지 문제를 모두 해결한다.

💡 내가 연구 할때 당시의 생각은(순전히 내 개인적인 생각). BC의 경우, 샘플이 너무 적고, 때문에 BC보다는 적당한 보상 설계와 시뮬레이션 환경이 답이라고 생각함. 하지만.. 최근의 연구 동향은 오히려 인간의 행동을 모방하는 BC 접근이 주목받는 모습을 보이는듯.

**TL;DR** — 행동 복제(BC)는 보상 함수 설계 없이 실제 상호작용으로부터 학습하는 자연스러운 플랫폼을 제공하며, 생성 모델은 다중 모달 시연 데이터셋을 처리하는 데 점별 정책보다 더 효과적임을 보여준다.

---

BC는 제어를 모방 학습 문제로 취급하여, 전문가 시연 데이터셋으로부터 정책을 학습한다. 단순한 regression은 다중 모달 행동 분포를 처리하는 데 한계가 있다 — 같은 상태에서 여러 전문가가 다른 행동을 보여줄 수 있기 때문이다. 생성 모델은 이 문제를 해결한다.

regression 모델은 특정 입력에 대한 출력의 평균을 학습하게되기때문에.. 전문가가 콜라를 왼손으로 10번, 오른손으로 10번 집으면, 그 평균은 오른손도 왼손도 아니게 됨.

하지만 생성모델의 경우, 행동 분포 전체를 학습하게되며, 실제 존재하는 행동만 나오게 됨.

## 4.1 생성 모델 간략 소개

**VAE (변분 오토인코더)**: 데이터를 잠재 공간으로 압축한 다음 재구성하는 방식으로, ELBO(Evidence Lower Bound)를 최적화한다. 간단하고 빠르지만 표현력이 제한적일 수 있다.

![image.png|481](image_03.webp)

💡 VAE는 두 부분으로 구성됨.

- **인코더**: 입력 데이터를 압축해서 작은 벡터 z(latent space)로 만듬.(전문가의 행동 chunk가 입력)
- **디코더**: z를 원래 데이터로 복원. z와 현재의 관측값(이미지, 관절 등)이 디코더의 입력

VAE는 "데이터를 압축했다가 복원하는 과정에서 확률적 잠재 공간을 학습하고, 그 공간에서 샘플링해서 새로운 데이터를 생성할 수 있게 하는 모델.

실제 로봇이 추론시에는 디코더만 사용하게됨(잠재변수 z를 샘플링 한 뒤, 관측값과 함께 디코더에 넣음

**확산 모델 (Diffusion Models)**: 데이터에 점진적으로 노이즈를 추가하고(순방향 과정), 이를 역방향으로 제거하는 방법을 학습하여(역방향 과정) 샘플을 생성한다. DDPM(Denoising Diffusion Probabilistic Model)과 DDIM(Denoising Diffusion Implicit Model이 대표적이다. 학습이 안정적이고 표현력이 높지만, 샘플링 시 다수의 역확산 단계가 필요하여 생성 속도가 느리다.

💡 Diffusion model은 데이터에서 노이즈를 추가하는 순방향 과정과, 이를 역방향으로 제거하는 모델을 학습시키는것. 점진적으로 랜덤 노이즈에서 입력 데이터로 노이즈를 거둬내는걸 학습시켜서, 완전한 랜덤 노이즈에서도 의미있는 정보를 뽑아냄. Stable Diffusion이나, Diffusion Policy(robotics)는 랜덤 노이즈에 텍스트 프롬프트나 카메라 이미지를 추가로 넣어서, 해당 프롬프트에 맞는 사진을 생성하거나, 해당 상태에 맞는 행동을 로봇이 하게됨.

**플로우 매칭 (Flow Matching)**: 노이즈와 데이터 분포 사이의 경로를 직접 학습하는 방식이다. 확산 모델과 달리 변분 하한 없이 간단한 회귀 손실로 학습할 수 있어 학습이 더 빠르고 안정적이다.

💡 Diffusion Model 은 뛰어난 생성 품질을 보여주지만, 샘플 생성 속도가 느리다는 단점.(수많은 denoising step을 반복하기 때문) Flow Matching은 위 문제를 해결하기 위해 등장한 개념.

노이즈 → 데이터로 이동하는 연속적 변화의 방향을 학습하여, 한번에 더 빠르게 이동하는 방법이라 할 수 있음.

연속적이고 결정적인 경로로 데이터 생성할 수 있음.(더 적은 스탭으로, 더 효율적으로 생성 가능)

diffusion model과 flow matching은 입출력이 같고(둘 다 노이즈를 입력으로, 의미있는 데이터를 생성하는것이 목적). diffusion model이 flow matching의 하위집합이라는 견해도 있음.

## 4.2 ACT (Action Chunking with Transformers)

ACT는 트랜스포머 기반 모방 학습 정책으로, 한 번에 여러 타임스텝의 행동을 예측하는 ‘액션 청킹’ 방식을 사용한다. 주요 구성 요소:

- **CVAE 인코더**: 학습 시 목표 행동 청크로부터 스타일 변수 z를 추출하여 다중 모달성을 처리
- **트랜스포머 디코더**: 인코딩된 스타일 변수 z와 관측값을 조건으로 하여 행동 청크를 생성
- **인퍼런스**: 추론 시에는 z를 사전 분포에서 샘플링하고, 행동 청크를 시간적 앙상블로 부드럽게 합성

lerobot에서의 사용:

```bash
lerobot-train \\
  --dataset.repo_id=${HF_USER}/my_dataset \\
  --policy.type=act \\
  --output_dir=outputs/train/act_tutorial \\
  --policy.device=cuda
```

💡 기본적인 BC는 현재 상태를 보고ㅡ 다음 행동 하나를 예측하지만, 로봇 제어에서는 아래 2가지 문제가 발생.

1. 매 타임스텝마다 독립적으로 행동을 예측하면, 연속된 행동 사이에 일관성이 없어짐.
    
    _석사논문 당시에도 이게 문제가 됐음. 당시에는 강제로 가속도를 제한하는 방식을 써서 문제해결을 회피함_
    
2. 같은 상태에서 여러 expert 행동을 학습한다면, 결국 평균행동이 나올 수 있음.(학습하지 않은 분포의 행동을 하게됨.)
    

위 두 문제를 ACT는 아래 방법으로 해결

1. Action Chunking
    - 행동을 하나씩 예측하는것이 아니라, 앞으로 할 행동 여러개를 묶어서 예측함. ”지금부터 앞으로 100 타임스텝의 행동을 한번에 출력해라”
    - 이럴 경우, 묶여져있는 행동은 서로 일관성이 생기게됨. 한번에 계획한 것이기 때문에 jittering(진동, 움찔거림)이 줄어들게됨.
2. CVAE(Conditional Variational Auto Encoder)로 다중 모달 처리
    - 같은 상태에서 왼쪽접근과 오른쪽 접근이 모두 가능한 경우 VAE구조를 사용(잠재변수 z가 어떤 스타일로 할건지를 정해줌)

**학습 / 추론 과정**

**학습할 때** (인코더 + 디코더 둘 다 사용):

1. **CVAE 인코더** (트랜스포머)가 전문가의 실제 행동 청크를 본다
2. 이 행동 청크를 잠재 변수 z로 압축한다 (z = "이 시연의 스타일")
3. **트랜스포머 디코더**가 z + 현재 관측(카메라 이미지, 관절 상태)을 받아서 행동 청크를 재생성한다
4. 재생성된 행동이 원래 전문가 행동과 비슷하도록 학습

즉 인코더는 "이 전문가가 뭘 하려는 건지 스타일을 파악"하고, 디코더는 "그 스타일대로 행동을 만들어내기"를 배우는 것.

**추론할 때** (디코더만 사용):

1. 인코더는 버린다 (전문가 행동을 볼 수 없으니까)
2. z를 표준 정규분포에서 랜덤 샘플링한다
3. 디코더가 z + 현재 관측을 받아서 행동 청크를 생성한다
4. 이 청크를 바로 다 실행하는 게 아니라, **시간적 앙상블**로 부드럽게 합성한다

시간적 앙상블은, 만약 각 acion chunk를 딱딱 끊어서 사용하는것이 아니라, 일정 스탭마다 추론하고, 나온 행동들을 가중평균하여 로봇의 다음 행동을 정하는것(action chunk 간의 변환이 자연스러워짐)

EX.

행동 청크가 100 타임스텝이라고 이고, 매 타임스텝마다 새로운 청크를 생성하면, 현재 시점의 행동에 대해 여러 청크가 겹쳐서 의견을 내는 상태가 됨.

- 100스텝 전에 생성한 청크의 마지막 행동
- 50스텝 전에 생성한 청크의 중간 행동
- 방금 생성한 청크의 첫 번째 행동

각 행동의 가중평균(최근 청크에 더 높은 가중치)으로 합성하면 행동 전환이 부드러워짐.

## 4.3 Diffusion Policy

Diffusion Policy는 확산 모델을 사용하여 행동 분포를 모델링하는 시각-운동 정책이다. 주요 특징:

- 노이즈에서 시작하여 조건부 역확산을 통해 행동 청크를 생성
- 두 가지 아키텍처 변형이 존재: CNN 기반과 트랜스포머 기반
- ACT에 비해 학습 안정성과 표현력이 더 높지만, 추론 시간이 더 길다

lerobot에서의 사용:

```bash
lerobot-train \\
  --dataset.repo_id=${HF_USER}/my_dataset \\
  --policy.type=diffusion \\
  --output_dir=outputs/train/diffusion_tutorial \\
  --policy.device=cuda
```

💡 Diffusion Policy는 확산모델로 같은 문제를 해결.

랜덤 노이즈에서 시작해서, 현재 관측을 조건으로 역확산을 반복하면 행동청크가 나오게됨.

stable diffusion이 텍스트 조건으로 이미지를 생성하듯, 로봇 관측을 조건으로 행동 청크를 생성함.

**학습할때:**

1. 전문가 행동 청크를 가져옴.
2. 랜덤한 스탭 t를 고르고, t만큼의 노이즈를 추가.
3. 신경망에 노이즈 섞인 행동 청크에서 노이즈가 뭔지 물어봄. 이때 행동 현재 관측을 조건으로 같이줌.
4. 예측한 노이즈와 실제 노이즈의 차이를 줄이도록 학습

**추론할때:**

1. 행동 청크 크기의 순수 랜덤 노이즈를 생성.
2. 현재 관측을 조건으로 노이즈 예측해서 빼기 반복(보통 10회정도)
3. 해당 청크의 행동을 순서대로 실행.

### ACT vs Diffusion Policy 비교

| |ACT|Diffusion Policy|
|---|---|---|
|**다중 모달 처리 방식**|VAE(잠재변수 z)|확산 모델(역확산)|
|**생성 방식**|z 샘플링 → 트랜스포머의 디코더 한번 통과|노이즈 → K번 확산을 반복|
|**추론 속도**|빠름(forward pass 한번)|느림(k번 반복해야함)|
|**표현력**|잠재변수 z가 가우시안 분포로 제한되기때문에, 복잡한 다중 모달 분포에 한계.|임의의 복잡한 분포를 표현할 수 있음. 봉우리 몇개건 역확산 과정이 알아서 분포의 모양대로 수렴함.|
|**학습 안정성**|가끔 KL밸런싱이 까다로움|매우 안정적(단순 노이즈 예측)|
|**모델 크기**|~80M|보통 더 큼|
|**실시간 제어**|유리함|추론 최적화가 필요함.|

**ACT를 쓰는 경우:**

- 빠른 프로토타이핑이 필요할 때
- 학습 데이터가 적을 때 (50개 시연 수준)
- 실시간 제어 지연이 중요할 때
- GPU가 약할 때

**Diffusion Policy를 쓰는 경우:**

- 학습 데이터가 풍부하고 행동 분포가 복잡할 때
- 학습 안정성이 중요할 때
- 추론 속도를 최적화(비동기 추론 등)로 보완할 수 있을 때

## 4.4 Optimized Inference

실제 로봇 제어에서는 추론 지연이 성능에 직접적으로 영향을 미침. 성능이 저하될 수도 있고, 지연이 해당 Task 완료에 치명적인 경우도 있음.

지연 최대한으로 줄이기위해(실시간으로 로봇의 행동을 추론하기 위해) lerobot에서는 아래 방식을 제안

- **비동기 추론**: 정책 추론(계획)을 별도 스레드에서 실행하여, 로봇이 현재 행동 청크를 실행하는 동안 다음 청크를 미리 계산
    
    - 이 경우, 약간 과거의 관측을 기반으로 행동하는꼴. 하지만 아래 3개때문에 약간의 지연이 허용되게됨.
        1. **추론하는 시간 동안 로봇과 환경이 극적으로 변하진 않음.** 어떤 물건이 0.1초 전에 저기있다면, 지금도 거의 저기 있음
        2. **액션 청킹 자체가 이를 완화함.** 앞으로 N 스탭의 행동 계획이기때문에, 시점 0에서 관측하고 앞으로 이렇게 할거라고 계획을 세웠기때문에 처음 몇스탭은 그냥 실행해도 유효함.
        3. **앙상블이 보정.** 새로운 청크가 들어오면, 최신 관측이 반영된 행동이 가중 평균에 포함되면서 점진적으로 보정됨.
- **액션 큐**: 미리 계산된 행동을 큐에 저장하여 현재 추론이 완료될 때까지 부드러운 실행을 보장
    
    - 가끔 추론이 늦어지거나, 실패하더라도 action queue에 쌓아둔 행동이 있으니, 로봇은 끊임없이 움직일 수 있음.
    
    ```jsx
    [큐]  행동5 → 행동4 → 행동3 → 행동2 → 행동1 → 로봇 실행
                                            ↑
                                  지금 이거 실행 중
                                  그 사이 뒤에서 새 행동이 큐에 추가됨
    ```

- **관측값 필터링**: 센서 노이즈와 드롭아웃을 처리하기 위한 필터를 제공(기본적인 신호처리 알고리즘을 통한 데이터보정을 제공)

|문제|필터링 방법|
|---|---|
|프레임 드롭|이전 값 사용 또는 보간|
|센서 노이즈 (떨림)|이동 평균, 저주파 통과 필터|
|타임스탬프 불일치|다른 센서 간 시간 동기화|
|이상치|범위 벗어나면 이전 값으로 대체|

# 5장. 범용 로봇 정책 (Generalist Robot Policies)

이 섹션에서는 다양한 태스크와 로봇 플랫폼에 걸쳐 작동할 수 있는 범용 모델(foundation models)을 다룬다. 이러한 모델은 대규모 다중 태스크 및 다중 로봇 데이터에서 학습된다.

💡    GPT-2 (2019): 영어만 그럭저럭
	GPT-3 (2020): 영어 잘함, 다른 언어 조금
	GPT-4 (2023): 수십 개 언어 + 코드 + 추론
	Claude (2024~): 더 다양한 능력

이런식으로 foundation model도 general 한 로봇 모델로의 진화를 고려함.

지금: 매니퓰레이션 위주, 비슷한 형태의 팔 로봇들 사이에서 범용성 가까운 미래: 매니퓰레이션 + 모바일 매니퓰레이션 먼 미래: 매니퓰레이션 + 로코모션 + 드론 + ... 진짜 범용

지금 당장 모든 로봇을 커버하진 못하지만, **접근 방식 자체가 그 방향으로 가고 있다**는 뜻.

현재 로보틱스의 파운데이션 모델은 “비슷한 종류의 로봇들 사이에서 여러 태스크를 하나의 모델”로 수준이며, “모든 종류의 로봇에서 모든 태스크를 수행”이 이 분야가 향해가는 장기적 목표임.

---

## 5.1 사전 준비: 모델과 데이터

로봇 파운데이션 모델의 발전은 두 가지 병행 추세에 의해 촉진되었다:

1. **대규모 언어 및 비전 모델의 발전**: VLM(Vision-Language Model)은 시각 인코더와 LLM을 결합하여 다중 모달 추론 능력을 제공
2. **로봇 데이터의 기하급수적 성장**: 공개 로봇 데이터셋의 수와 규모가 급격히 증가

VLM을 로봇 제어에 적용한 것이 **VLA(Vision-Language-Action) 모델**이다.

---

## 5.2 VLA (Vision-Language-Action) 모델

VLA는 Vision, Language를 입력으로, Actoin을 출력하는 모델.

VLM은 VLA를 위한 자연스러운 backbone을 제공(VLM의 시각 이해와 언어 추론 능력을 활용하여, 출력 공간만 행동으로 확장)

### 5.2.1 VLMs for VLAs

VLM은 시각 인코더(예: ViT)와 LLM을 결합하여 이미지와 텍스트를 함께 처리할 수 있으먀. 이러한 모델은 장면 이해, 물체 인식, 공간 추론 능력을 기본적으로 갖추고 있어, 로봇 제어를 위한 강력한 사전 학습 기반을 제공한다.

인터넷 텍스트로 사전학습한 LLM을 파인튜닝하여 하여 사용할 수 있는 Chat Bot이 되듯이,

인터넷이미지 + 텍스트로 사전학습된 VLM을 로봇 데이터로 파인튜닝하여 VLA가 됨.

---

## 5.3 π₀ (Pi-Zero)

π₀는 Physical Intelligence에서 개발한 VLA로, 사전 학습된 VLM(PaLI-Gemma)을 백본으로 사용한다. 주요 특징:

- **플로우 매칭 액션 헤드**: VLM의 출력을 플로우 매칭을 통해 연속적인 행동으로 변환
    - VLM 백본이 장면과 명령을 이해한 결과를 받아서, 실제 로봇 행동(관절 각도 / 속도)를 생성하는 모듈임.
    - Flow matching을 통한 행동 청크를 사용함(노이즈에서 행동 청크를 생성함)

- **2단계 학습**:
    1. 대규모 다양한 데이터에서 사전 학습
        - 다양한 로봇, 다양한 태스크에서의 대규모 시연 데이터로 학습. 단일 팔, 양팔, 이동로봇 등’의 여러 플랫폼의 데이터를 섞어서 학습.
        - “로봇으로 물체를 조작하는게 이런거구나” 를 학습함.
        
    2. 특정 태스크/로봇에 맞게 미세 조정
    - 자기가 가진 로봇 + 자기가 원하는 태스크의 시연 데이터로 미세조정.

- **크로스 엠보디먼트**: 다양한 로봇 플랫폼에서 작동 가능
    - 이미 1단계학습에서 다양한 로봇의 데이터를 보면서 학습했기때문에, 로봇 플랫폼이 바뀌어도 2단계 미세조정을 통해 적응할 수 있음.
    - 미세조정하기전에는 여러 플랫폼에서 그럭저럭 동작을 하고, 미세 조정을 하면 특정 로봇에서 매우 잘 작동하게됨.

lerobot에서의 사용:

```bash
lerobot-train \\
  --policy.type=pi0 \\
  --dataset.repo_id=${HF_USER}/my_dataset \\
  --output_dir=outputs/train/pi0_tutorial \\
  --policy.device=cuda
```

## 5.4 SmolVLA

SmolVLA는 Hugging Face에서 개발한 경량 VLA로, π₀보다 훨씬 작은 모델 크기로 경쟁력 있는 성능을 달성한다. 주요 특징:

- **SmolVLM 백본**: 소형 VLM을 기반으로 하여 학습과 추론 비용을 절감(Hugging face에서 개발한 VLM)
- **플로우 매칭 액션 전문가**: π₀와 유사하게 플로우 매칭을 사용하지만, 더 작은 규모로 구현
- **접근성**: lerobot에 완전히 통합되어 쉽게 사용할 수 있다

lerobot에서의 사용:

```bash
lerobot-train \\
  --policy.type=smolvla \\
  --dataset.repo_id=${HF_USER}/my_dataset \\
  --output_dir=outputs/train/smolvla_tutorial \\
  --policy.device=cuda
```

# 6장. 결론 (Conclusions)

이 튜토리얼은 현대 로봇 학습의 전반을 다루었으며, 고전 로봇공학에서 출발하여 강화학습, 모방 학습, 그리고 범용 로봇 정책까지 이르는 여정을 안내했다.

핵심 메시지는 명확하다: 강력한 생성 모델, 대규모 데이터셋, 오픈소스 인프라, 그리고 실용적 배포 고려사항의 수렴은 로봇 학습을 가정 보조부터 산업 자동화, 과학 탐구에 이르기까지 다양한 응용 분야에서 상당한 영향을 미칠 수 있는 위치에 놓았다.

**주요 흐름 정리:**

- **고전 로봇공학 (2장)**: 동역학 기반 방법의 기초와 한계를 제시하여 학습 기반 접근의 필요성을 동기 부여
- **강화학습 (3장)**: MDP 프레임워크부터 SAC, RLPD, HIL-SERL까지, 실제 환경에서 1-2시간 내 고성능 정책을 학습할 수 있음을 보여줌
- **모방 학습 (4장)**: VAE, 확산 모델, 플로우 매칭의 생성 모델 기반 위에 ACT와 Diffusion Policy라는 두 가지 핵심 정책을 설명
- **범용 정책 (5장)**: VLA 패러다임을 소개하고, π₀와 SmolVLA를 통해 언어 조건부 다중 태스크 로봇 제어의 가능성을 보여줌

모든 코드 예제는 lerobot으로 구현되어 있으며, 시뮬레이션과 기존 데이터셋을 활용하여 실물 로봇 없이도 학습 파이프라인의 핵심을 경험할 수 있다.
